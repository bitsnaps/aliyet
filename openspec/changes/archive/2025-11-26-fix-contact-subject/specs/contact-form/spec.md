## ADDED Requirements

### Requirement: The contact form "Subject" field must provide specific options.

The "Subject" field in the contact form MUST be a dropdown list (`USelect`) containing a predefined set of options to standardize user inquiries.

#### Scenario: User selects a subject from the contact form
- The "Subject" field in the contact form should be a dropdown menu.
- The dropdown menu should contain the following options:
  - 'Maintenance'
  - 'Installation'
  - 'Sales'
  - 'Others'
- When a user selects an option, the value should be correctly submitted with the form.
